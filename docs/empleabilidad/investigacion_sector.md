# Exploración del Sector IT

He estado investigando tres empresas bastante potentes donde me gustaría trabajar o que me sirven de referencia:

1. **Telefónica Tech:** Son especialistas en ciberseguridad y servicios en la nube para grandes infraestructuras.
2. **Amazon Web Services (AWS):** El gigante del Cloud. Buscan administradores de bases de datos y expertos en redes para mantener sus centros de datos.
3. **NTT Data:** Es una consultora tecnológica que gestiona la digitalización de empresas trabajando mucho con Active Directory y entornos híbridos.
